1. Официальный способ: скачивание с сайта Canon

Самый надёжный метод — загрузить драйвер непосредственно с ресурса производителя. Canon регулярно обновляет ПО для своей техники, исправляя ошибки совместимости и добавляя поддержку новых ОС. Вот как это сделать правильно:

Перейдите на официальный сайт Canon (раздел поддержки) и в строке поиска введите точное название модели: i-SENSYS LBP6020B. Система автоматически предложит список доступных загрузок. Обратите внимание на:

  • 🖥️ Операционную систему — выберите вашу версию Windows (7/8.1/10/11), macOS или Linux. Для LBP6020B доступны драйверы даже для устаревших систем вроде Windows XP (но без гарантии полной функциональности).
  • 📄 Тип файла — обычно это .exe для Windows или .dmg для Mac. Для Linux может потребоваться .deb или .rpm.
  • 🔄 Дата обновления — проверьте, что драйвер актуален (не старше 2022 года). Устаревшие версии могут не поддерживать современные протоколы печати.

После выбора нужного файла нажмите Загрузить. Обычно вес драйвера для LBP6020B не превышает 50–70 МБ. Если сайт предлагает скачать пакет ПО (например, Canon PRINT Business), знайте: он включает не только драйвер, но и утилиты для мониторинга расходников, что полезно для офисного использования.

💡

Если сайт Canon запрашивает серию принтера, а вы не знаете её — посмотрите на наклейку сзади устройства. Серия обычно указана рядом с моделью (например, LBP6020B/001).

2. Установка драйвера вручную через Диспетчер устройств

Если автоматическая установка не сработала или принтер не определяется, можно добавить драйвер вручную. Этот метод полезен, когда:

  • 🔌 Принтер подключён по USB, но Windows выдаёт ошибку "Устройство не опознано".
  • 🖨️ В списке принтеров отображается неизвестное устройство без возможности печати.
  • 📥 Вы скачали драйвер, но установщик не запускается (например, из-за блокировки антивирусом).

Инструкция для Windows 10/11:

  1. Подключите принтер к компьютеру через USB (используйте порт 2.0, если 3.0 не работает).
  2. Откройте Диспетчер устройств (нажмите Win + X → выберите соответствующий пункт).
  3. Найдите в списке раздел "Очереди печати" или "Другие устройства" — там должен отобразиться LBP6020B с восклицательным знаком.
  4. Кликните правой кнопкой по устройству → "Обновить драйвер" → "Выполнить поиск драйверов на этом компьютере".
  5. Укажите путь к папке с загруженным драйвером (обычно это C:\Downloads\Canon_LBP6020B_Driver или аналогичная).
  6. Подтвердите установку и перезагрузите компьютер.

4. Установка драйвера через Windows Update

Microsoft регулярно добавляет в свою базу драйверы для популярных устройств, включая принтеры Canon. Этот метод подходит, если:

  • 🔄 У вас нет доступа к официальному сайту.
  • 📥 Вы не хотите скачивать файлы вручную.
  • 🖥️ Ваша ОС — Windows 10/11 (в более старых версиях база драйверов ограничена).

Как установить драйвер через обновление Windows:

  1. Подключите принтер к компьютеру и включите его.
  2. Откройте Параметры → Обновление и безопасность → Центр обновления Windows.
  3. Нажмите "Проверка наличия обновлений".
  4. Если система найдёт драйвер для LBP6020B, он установится автоматически.
  5. Перезагрузите компьютер и проверьте работу принтера.

Если принтер не определился:

  • 🔍 Попробуйте вручную запустить поиск драйверов: откройте Диспетчер устройств, найдите LBP6020B, кликните правой кнопкой → "Обновить драйвер" → "Автоматический поиск".
  • 📡 Убедитесь, что у вас стабильное подключение к интернету (Windows скачивает драйверы онлайн).
  • ⏳ Подождите 10–15 минут — иногда поиск занимает время.
💡

Драйверы из Windows Update могут быть не самой свежей версии, но они гарантированно совместимы с вашей ОС и прошли проверку Microsoft.

5. Совместимость с macOS и Linux: особенности установки

Принтер Canon i-SENSYS LBP6020B официально поддерживается не только Windows, но и другими системами. Однако процесс установки там имеет нюансы.

Для macOS (Catalina, Big Sur, Ventura, Sonoma):

  • 🍎 Скачайте драйвер с сайта Canon (раздел "Mac"). Для этой модели актуальна версия Canon UFR II/UFRII LT Printer Driver v10.19.11.
  • 📦 Откройте загруженный файл .dmg и запустите установщик.
  • 🔌 Подключите принтер только после установки драйвера (в отличие от Windows, где порядок не важен).
  • 🖨️ Добавьте принтер через "Системные настройки → Принтеры и сканеры", выбрав модель LBP6020B вручную.

Для Linux (Ubuntu, Debian, Fedora):

  • 🐧 Canon предоставляет драйверы в формате .deb (Debian/Ubuntu) и .rpm (Fedora/OpenSUSE). Скачайте подходящий пакет с официального сайта.
  • 📥 Установите зависимости (если требуется):
    • sudo apt install libcups2 libcupsimage2
  • 🔧 Установите драйвер через терминал:
    • sudo dpkg -i cndrvcups-lbpxx_*.deb
  • 🖼️ Добавьте принтер через CUPS (откройте в браузере localhost:631) или стандартный менеджер печати.
Проблемы с печатью в Linux?

Если принтер добавился, но не печатает:

1. Проверьте, что служба cups запущена:

sudo systemctl status cups

2. Убедитесь, что пользователь входит в группу lpadmin:

sudo usermod -aG lpadmin $USER

3. Перезагрузите систему.

Внимание! Для Linux может потребоваться дополнительная настройка SANE (для сканирования), так как LBP6020B не поддерживает эту функцию "из коробки". Также некоторые дистрибутивы (например, Arch Linux) требуют сборки драйвера из AUR.

6. Типичные ошибки и их решение

Даже после установки драйвера принтер может работать некорректно. Вот самые распространённые проблемы и способы их устранения:

Ошибка Возможная причина Решение
"Притер не отвечает" Конфликт драйверов, неверное подключение USB Удалите все драйверы Canon через Панель управления → Программы, затем установите заново
"Документ не печатается" (застревает в очереди) Сбой службы печати Перезапустите службу Spooler: 
net stop spooler & net start spooler
Печать идёт, но текст "смазан" Низкое качество тонера или неверные настройки драйвера Замените картридж или в настройках печати выберите "Высокое качество"
Притер определяется, но не печатает по Wi-Fi LBP6020B не поддерживает беспроводную печать (только USB) Используйте USB-кабель или приобретите принт-сервер

Если принтер издаёт необычные звуки (скрип, стук) или мигает оранжевым индикатором — проблема может быть механической. В этом случае:

  • 🔧 Проверьте, нет ли замятия бумаги (аккуратно извлеките лоток и осмотрите ролики).
  • 📦 Убедитесь, что в лотке лежит бумага подходящего формата (не толще 80 г/м²).
  • 🛠️ Если звук похож на скрежет — возможно, изношены шестерни приводного механизма (требуется ремонт).
💡

Если после установки драйвера принтер печатает "мусор" (нечитаемые символы), попробуйте сменить порт в настройках принтера: откройте Панель управления → Устройства и принтеры, кликните правой кнопкой по LBP6020B → Свойства принтера → Порты и выберите другой USB-порт.

7. Обновление драйвера и прошивки принтера

Регулярное обновление ПО для Canon i-SENSYS LBP6020B помогает избежать проблем с совместимостью и улучшает производительность. Проверять актуальность драйвера стоит:

  • 🔄 Раз в 6–12 месяцев (или после крупных обновлений Windows/macOS).
  • 🖥️ Если принтер начал работать медленнее или появились ошибки.
  • 📦 После замены картриджа (иногда новые чипы требуют обновлённого ПО).

Как обновить драйвер:

  1. Скачайте свежую версию с сайта Canon (как описано в первом разделе).
  2. Удалите старый драйвер через Панель управления → Программы и компоненты.
  3. Установите новый драйвер и перезагрузите компьютер.

Для обновления прошивки принтера:

  • 📥 Скачайте файл прошивки с официального сайта (раздел "Firmware").
  • 🔌 Подключите принтер к компьютеру напрямую (без USB-хабов).
  • 🖼️ Запустите файл прошивки и следуйте инструкциям (обычно процесс занимает 2–3 минуты).
💡

Не прерывайте процесс обновления прошивки! Это может привести к "окирпичиванию" принтера (он перестанет включаться). Если обновление зависло — дождитесь 10 минут, затем отключите и включите принтер.

Внимание! Прошивка для LBP6020B выпускается редко (последняя версия — 1.07 от 2019 года). Если ваш принтер работает стабильно, обновлять прошивку без необходимости не рекомендуется.

8. Где взять ПО для расширенных функций

  • 🔍 Через магазин приложений (например, Microsoft Store для Windows).

Для установки:

  1. Скачайте нужную программу (например, Canon_PRINT_Business_v2.8.0.exe).
  2. Запустите установщик от имени администратора.
  3. Следуйте инструкциям мастера, выбрав LBP6020B из списка поддерживаемых устройств.
  4. Перезагрузите компьютер.

Внимание! Некоторые утилиты (например, Canon My Printer) могут конфликтовать с антивирусами (например, Kaspersky блокирует доступ к портам принтера). В этом случае добавьте программу в исключения антивируса.

Как удалить ненужное ПО Canon?

1. Панель управления → Программы и компоненты.

2. Или используйте утилиту Revo Uninstaller для полной очистки.

FAQ: Частые вопросы по принтеру Canon i-SENSYS LBP6020B

🔹 Можно ли подключить LBP6020B по Wi-Fi или только через USB?

К сожалению, Canon i-SENSYS LBP6020B не имеет встроенного модуля Wi-Fi. Подключение возможно только по USB. Однако вы можете использовать внешний принт-сервер (например, TP-Link TL-PS110U), чтобы сделать принтер сетевым. Альтернатива — подключить принтер к роутеру с USB-портом (если роутер поддерживает функцию принт-сервера).

🔹 Почему принтер печатает полосы или бледный текст?

Эта проблема обычно связана с:

  • 📉 Низким уровнем тонера в картридже (замените или встряхните картридж).
  • 🔧 Неправильными настройками драйвера (выберите режим "Высокое качество" в свойствах печати).
  • 🛠️ Износом фотобарабана (требуется замена).
  • 📄 Некорректным типом бумаги (используйте стандартную офсетную бумагу 80 г/м²).

Также проверьте, не установлен ли в настройках принтера режим "Экономичная печать".

🔹 Как сбросить счётчик тонера на LBP6020B?

Canon i-SENSYS LBP6020B не имеет аппаратной кнопки сброса счётчика, но можно обнулить показания программно:

  1. Откройте Панель управления → Устройства и принтеры.
  2. Кликните правой кнопкой по LBP6020B → Свойства принтера.
  3. Перейдите на вкладку "Обслуживание" или "Настройки устройства".
  4. Найдите опцию "Сброс счётчика тонера" (в некоторых версиях драйвера она скрыта под "Дополнительные настройки").
  5. Подтвердите сброс и перезагрузите принтер.

Внимание! Сброс счётчика не добавляет тонер в картридж! Это просто обнуляет показания, чтобы принтер не блокировал печать. Если тонера действительно нет, сброс может привести к повреждению фотобарабана.

🔹 Можно ли использовать совместимые картриджи вместо оригинальных?

Да, для LBP6020B подходят совместимые картриджи (например, от Katun, Pelikan или LD Products). Однако учитывайте:

  • ✅ Плюсы: цена в 2–3 раза ниже оригинала, часто больший ресурс.
  • ❌ Минусы:
    • Качество печати может уступать оригиналу (особенно при печати графики).
    • Возможны проблемы с счётчиком тонера (принтер может показывать некорректный уровень).
    • Риск протечки тонера при низком качестве сборки.

Если решите использовать совместимый картридж:

  • 🛒 Покупайте у проверенных продавцов (например, на OZON или Wildberries с высоким рейтингом).
  • 🔍 Проверяйте, что картридж поддерживает чип сброса (иначе принтер может блокировать печать).
  • 📄 Сохраняйте чек — некоторые продавцы дают гарантию на совместимые картриджи.
