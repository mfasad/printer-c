Canon PIXMA MG2900: полная инструкция по настройке принтера для печати и сканирования

Мультифункциональный принтер Canon PIXMA MG2900 остаётся популярным выбором для домашнего использования благодаря компактным размерам, доступной цене и возможности печати/сканирования/копирования. Однако даже с такой простой моделью пользователи часто сталкиваются с трудностями при первом подключении — от отсутствия драйверов до ошибок соединения по Wi-Fi. Эта статья поможет разобраться во всех нюансах настройки без обращения в сервисный центр.

Мы рассмотрим все возможные способы подключения (проводной и беспроводной), установку программного обеспечения на Windows/macOS, базовые настройки печати и сканирования, а также типичные ошибки, которые возникают у владельцев MG2900. Особое внимание уделим совместимости с современными ОС — многие инструкции в сети устарели и не учитывают изменения в последних версиях Windows 11 или macOS Ventura.

Если вы только распаковали принтер или столкнулись с проблемами после переезда/переустановки системы — этот гайд станет вашей шпаргалкой. Для удобства каждый раздел содержит пошаговые инструкции с визуальными подсказками и чек-листы для самопроверки. Начнём с самого важного — выбора способа подключения.

1. Выбор способа подключения: USB vs Wi-Fi

Перед настройкой определитесь, как принтер будет соединяться с компьютером или мобильными устройствами. У Canon PIXMA MG2900 есть два основных интерфейса:

  • 🔌 USB-подключение — надёжный вариант для стационарного ПК. Требует физического кабеля (входит в комплект), но гарантирует стабильную работу без задержек. Подходит для офисов или если роутер далеко от принтера.
  • 📶 Wi-Fi — удобно для ноутбуков, планшетов и смартфонов. Позволяет печатать с нескольких устройств одновременно, но может тормозить при слабом сигнале или конфликтах IP-адресов.

Какой способ выбрать? Если принтер будет использоваться только с одним компьютером — USB проще в настройке и реже даёт сбои. Для семейного использования или печати со смартфонов лучше настроить Wi-Fi. Обратите внимание: MG2900 не поддерживает подключение по Ethernet (нет LAN-порта) и не имеет дисплея — все настройки выполняются через ПО на ПК.

Важный нюанс: при первом подключении по Wi-Fi принтер временно создаёт собственную сеть для настройки (режим "Direct Connection"). Это не постоянное решение — после конфигурации его нужно перевести в режим работы через ваш домашний роутер. Подробнее об этом в следующем разделе.

2. Подключение принтера к компьютеру по USB

Самый простой способ начать работу с Canon MG2900 — соединить его с ПК через USB-кабель. Вот пошаговая инструкция:

  1. Подготовьте принтер:
    • 📦 Распакуйте устройство и удалите все защитные наклейки (особенно внутри лотка для бумаги).
    • ⚡ Подключите блок питания к розетке и нажмите кнопку включения (справа на панели). Дождитесь, пока индикатор перестанет мигать.
    • 📄 Загрузите бумагу в лоток (максимум 100 листов формата A4).
  2. Установите драйверы:
    • 💻 Вставьте диск из комплекта в привод ПК (если он есть) или скачайте ПО с официального сайта Canon (выберите модель PIXMA MG2900).
    • 🔍 Запустите файл установки и следуйте мастеру. На этапе выбора типа подключения укажите USB-соединение.
  3. Соедините устройства:
    • 🔗 Подключите принтер к ПК после установки драйверов (не наоборот!). Используйте кабель из комплекта или сертифицированный USB 2.0.
    • 🖱️ Дождитесь автоматического определения устройства в системе (в Windows проверьте в Панель управления → Устройства и принтеры).

Если принтер не определяется:

  • 🔄 Перезагрузите и ПК, и принтер.
  • 🔌 Попробуйте другой USB-порт (желательно на задней панели системного блока).
  • 🛠️ Обновите драйверы вручную через Диспетчер устройств (раздел "Очереди печати").
⚠️ Внимание: Некоторые пользователи сталкиваются с ошибкой 0x00000002 при подключении через USB 3.0 (синие порты). В этом случае используйте порт USB 2.0 (чёрного цвета) или установите обновление KB5006746 для Windows 10/11.

3. Настройка беспроводного подключения (Wi-Fi)

Для подключения Canon MG2900 по Wi-Fi потребуется временно использовать USB-кабель (даже если потом вы его отключите). Это необходимо для передачи настроек сети на принтер. Следуйте алгоритму:

Шаг 1. Активируйте режим Wi-Fi на принтере

  1. Убедитесь, что принтер включён и подключён к ПК по USB.
  2. Запустите программу Canon IJ Network Tool (устанавливается вместе с драйверами).
  3. В главном окне нажмите Настройка → Настройка беспроводной сети.
  4. Выберите Подключение через кабель USB и следуйте инструкциям мастера.

Шаг 2. Выберите сеть и введите пароль

  • 📡 Программа предложит список доступных Wi-Fi сетей. Выберите вашу (убедитесь, что роутер включён и транслирует сеть в диапазоне 2.4 GHz — MG2900 не поддерживает 5 GHz).
  • 🔑 Введите пароль от Wi-Fi. Если используете WPS, нажмите кнопку WPS на роутере в течение 2 минут.
  • 🔄 Дождитесь завершения настройки (индикатор Wi-Fi на принтере перестанет мигать).

Шаг 3. Отключите USB-кабель

После успешного подключения:

  1. Отсоедините USB-кабель от принтера.
  2. Перезагрузите принтер (выключите и включите кнопкой питания).
  3. Убедитесь, что индикатор Wi-Fi горит зелёным — это значит, что соединение активно.

4. Установка драйверов и ПО для Windows и macOS

Без правильных драйверов принтер не будет распознаваться системой, даже если физически подключён. Рассмотрим процесс для разных ОС.

Для Windows 10/11:

  1. Скачайте полный пакет драйверов для PIXMA MG2900 (выберите вашу версию Windows).
  2. Запустите файл MG2900series-Full-Driver-Setup.exe.
  3. На этапе выбора компонентов отметьте:
    • 📄 MP Drivers — основные драйверы для печати/сканирования.
    • 🖼️ IJ Scan Utility — утилита для сканирования.
    • 🌐 IJ Network Tool — для настройки Wi-Fi.
  • Подключите принтер к ПК только когда программа попросит.

    • Для macOS (Ventura/Monterey/Sonoma):

    • 🍎 Скачайте драйверы с сайта Canon (раздел "Mac").
    • Откройте файл .dmg и запустите установщик.
    • После установки перейдите в Системные настройки → Принтеры и сканеры, нажмите "+" и выберите MG2900 из списка.
    • Если принтер не отображается, нажмите Добавить принтер по IP и введите адрес, полученный через Canon IJ Network Tool.

    Для мобильных устройств (Android/iOS) используйте официальное приложение Canon PRINT Inkjet/SELPHY (доступно в App Store и Google Play). Оно поддерживает печать фотографий, документов и сканирование прямо со смартфона.

    Что делать, если драйверы не устанавливаются?

    Если установщик выдаёт ошибку, попробуйте:

    1. Отключить антивирус (он может блокировать установку).

    2. Запустить файл от имени администратора (ПКМ → "Запуск от имени администратора").

    3. Удалить старые драйверы через Панель управления → Программы и компоненты.

    4. Использовать веб-установщик вместо офлайн-пакета.

    5. Базовые настройки печати и сканирования

    После подключения принтера остаётся настроить параметры печати и сканирования под ваши задачи. Рассмотрим ключевые моменты.

    Настройка печати:

    • 📑 Формат бумаги: По умолчанию установлен A4. Чтобы изменить, откройте свойства принтера в документе (например, в Word: Файл → Печать → Свойства) и выберите нужный формат.
    • 🎨 Качество печати: Для текстовых документов достаточно Черновик (300 dpi), для фотографий выбирайте Высокое (1200 dpi).
    • 🖨️ Двусторонняя печать: MG2900 не поддерживает автоматическую двустороннюю печать. Для ручного режима в настройках выберите Печать на обеих сторонах (вручную).
    • 🔒 Экономия чернил: Включите опцию Быстрая печать или Экономичный режим для уменьшения расхода.

    Настройка сканирования:

    1. Запустите программу IJ Scan Utility (устанавливается с драйверами).
    2. Поместите документ на стекло сканера лицевой стороной вниз (верхний левый угол — ориентир).
    3. Выберите тип сканирования:
      • 📄 Документ — для текстов (сохраняет в PDF).
      • 🖼️ Фото — для изображений (JPEG/PNG).
      • 📧 Отправить по email — автоматически создаёт письмо с вложением.
  • Настройте разрешение: 150-300 dpi для документов, 600 dpi для фотографий.
    • 💡

    Для сканирования нескольких страниц в один PDF-файл используйте режим Многостраничный PDF в IJ Scan Utility. Это сэкономит время на объединение файлов.

    Если сканер не реагирует:

    • 🔌 Проверьте, закрыта ли крышка сканера (даже небольшой зазор мешает работе).
    • 🖱️ Перезапустите программу IJ Scan Utility от имени администратора.
    • 🔄 Обновите драйверы сканера через Диспетчер устройств (раздел "Устройства обработки изображений").

    6. Решение типичных ошибок и проблем

    Даже после правильной настройки Canon MG2900 может выдавать ошибки. Разберём самые частые из них и способы их устранения.

    Ошибка Причина Решение
    E02 (мигает оранжевым) Закончилась бумага или замятие Проверьте лоток, удалите застрявшую бумагу, перезагрузите принтер
    E03 (мигает 3 раза) Заклинило картридж или крышка открыта Извлеките и установите картриджи заново, закройте крышку
    E04 (мигает 4 раза) Нет чернил или картридж не распознаётся Проверьте уровень чернил, очистите контакты картриджа салфеткой
    B200 Аппаратная ошибка печатной головки Выключите принтер на 10 минут, если не поможет — обратитесь в сервис
    Принтер не печатает после замены картриджа Сброс счётчика или несовместимый картридж Используйте оригинальные картриджи PG-545/CL-546 или выполните сброс через утилиту Service Tool

    Проблемы с подключением:

    • 🖨️ Принтер не отображается в сети: Проверьте, что он подключён к тому же Wi-Fi, что и ПК. Перезапустите службу печати в Windows (services.msc → Print Spooler).
    • 📡 Постоянно теряется соединение: Назначьте принтеру статический IP в настройках роутера или уменьшите расстояние между устройствами.
    • 🔌 USB-порт не работает: Попробуйте другой кабель или порт. Если принтер издаёт звуковые сигналы при подключении — проблема в порту ПК.

    Проблемы с печатью:

    • 🖼️ Полосы на отпечатках: Запустите Очистку печатной головки через программу Canon MG2900 series Printer Driver (вкладка Обслуживание).
    • 🎨 Цвета не совпадают с оригиналом: В настройках драйвера выберите Управление цветом: ICM и профиль sRGB.
    • 📄 Бумага зажевывается: Используйте бумагу плотностью 64–105 г/м². Выровняйте стопку перед загрузкой.
    ⚠️ Внимание: Если после замены картриджей принтер выдаёт ошибку E16 (неоригинальные чернила), а печать невозможна — это означает, что активировалась защита от нелицензионных расходников. В этом случае поможет только сброс счётчика через сервисное ПО или обращение в центр Canon. Использование "обнуляющих" чипов может привести к поломке печатной головки.

    7. Обслуживание и уход за принтером

    Чтобы Canon MG2900 прослужил дольше, следуйте простым правилам эксплуатации:

    Чистка и хранение:

    • 🧹 Очистка от пыли: Раз в месяц протирайте корпус и стекло сканера мягкой салфеткой. Для внутренних деталей используйте пылесос с маленькой насадкой (выключите принтер!).
    • 🌡️ Условия хранения: Держите принтер вдали от прямых солнечных лучей и источников тепла. Оптимальная температура: 15–30°C, влажность: 10–80%.
    • 🔋 Длительный простой: Если принтер не используется больше 2 недель, извлеките бумагу из лотка и картриджи (храните их в герметичных пакетах).

    Обслуживание картриджей:

    • 🖨️ Периодическая печать: Раз в 1–2 недели печатайте тестовую страницу, чтобы чернила не засыхали в соплах.
    • 🔄 Замена картриджей: Используйте только оригинальные PG-545 (чёрный) и CL-546 (цветной). Аналоги могут повредить печатную головку.
    • 🚫 Что нельзя делать:
      • Заклеивать вентиляционные отверстия на картриджах.
      • Доливать чернила в оригинальные картриджи (риск протечки).
      • Хранить картриджи рядом с нагревательными приборами.

    Профилактика засохших чернил:

    1. Если принтер не печатал долго, запустите Глубокую очистку печатной головки (вкладка Обслуживание в драйвере).
    2. Для удаления засохших чернил используйте специальную жидкость (например, Canon Cleaning Cartridge) или изопропиловый спирт (только для внешней очистки!).
    3. Не используйте воду или бытовые моющие средства!
    💡

    Если принтер выдаёт ошибку E05 (перегрев), выключите его на 30 минут. Эта проблема часто возникает при длительной печати в жарком помещении. Убедитесь, что вентиляционные отверстия на задней панели не закрыты.

    8. Альтернативные способы печати (без ПК)

    Canon PIXMA MG2900 поддерживает печать без компьютера — напрямую со смартфонов, флешек или облачных сервисов. Рассмотрим все варианты.

    Печать со смартфона (Android/iOS):

    1. Установите приложение Canon PRINT Inkjet/SELPHY.
    2. Подключите телефон к той же Wi-Fi сети, что и принтер.
    3. В приложении выберите документ или фото, настройте параметры и нажмите Печать.

    Печать с USB-флешки:

    • 📁 MG2900 не имеет USB-порта для флешек, но вы можете использовать адаптер USB OTG + смартфон как посредник.
    • 📱 Подключите флешку к телефону, откройте файл в приложении Canon PRINT и отправьте на печать.

    Облачная печать (Google Cloud Print, AirPrint):

    • ☁️ Для Google Cloud Print:
      1. Добавьте принтер в свой аккаунт Google через веб-интерфейс.
      2. Отправляйте документы на печать из Gmail, Google Docs или Chrome.
    • 🍎 Для AirPrint (только macOS/iOS):
      1. Убедитесь, что принтер подключён к той же сети, что и устройство Apple.
      2. Выберите Печать в любом приложении и найдите MG2900 в списке принтеров.

    Для печати с Linux используйте драйверы Gutenprint или CUPS. Установите их через терминал:

    sudo apt-get install printer-driver-gutenprint cups
    ⚠️ Внимание: Функции облачной печати могут быть ограничены из-за устаревшей прошивки принтера. Если MG2900 не отображается в списке устройств для Google Cloud Print, обновите прошивку через Canon IJ Printer Utility (вкладка Настройки → Обновление прошивки).

    FAQ: Частые вопросы по Canon PIXMA MG2900

    🔹 Можно ли подключить MG2900 к роутеру через кабель Ethernet?

    Нет, у этой модели нет порта RJ-45 для проводного подключения к сети. Единственные доступные интерфейсы — USB и Wi-Fi (2.4 GHz).

    🔹 Почему принтер печатает полосы даже после замены картриджей?

    Это может быть вызвано:

    • Засохшими чернилами в печатной головке (запустите Глубокую очистку 2–3 раза).
    • Плохим контактом между картриджем и головкой (извлеките и установите картриджи заново).
    • Использованием неоригинальных чернил (они могут забивать сопла).

      • Если проблема не исчезает, возможно, повреждена печатная головка — в этом случае требуется ремонт.

    🔹 Как сбросить счётчик картриджей после заправки?

    Официально Canon не предоставляет инструментов для сброса счётчика на MG2900. Однако можно попробовать:

    1. Использовать сервисную утилиту Service Tool (доступна на специализированных форумах).
    2. Отключить проверку уровня чернил в настройках драйвера (Обслуживание → Настройки принтера → Отключить мониторинг уровня чернил).

    ⚠️ Предупреждение: Сброс счётчика может привести к неправильной работе принтера или аннулированию гарантии.

    🔹 Поддерживает ли MG2900 печать на CD/DVD-дисках?

    Нет, эта модель не имеет лотка для печати на дисках. Для таких задач рассмотрите более продвинутые модели серии Canon PIXMA TS или TR.

    🔹 Как отсканировать документ в PDF без компьютера?

    С помощью приложения Canon PRINT на смартфоне:

    1. Поместите документ на стекло сканера.
    2. В приложении выберите Сканер → Документ → Сохранить в PDF.
    3. Настройте область сканирования и сохраните файл в память телефона или облако.
