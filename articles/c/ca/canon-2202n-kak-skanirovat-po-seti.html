Сканирование по сети на Canon i-SENSYS LBP2202N: полное руководство от настройки до устранения ошибок

МФУ Canon i-SENSYS LBP2202N — компактное решение для малого офиса, но его возможности сетевого сканирования часто остаются невостребованными из-за сложностей с настройкой. В отличие от моделей с экраном, здесь все параметры задаются через веб-интерфейс или драйвер, что пугает новичков. Между тем, правильно настроенный сетевой сканинг экономит время: документы сразу сохраняются на ПК, в облако или отправляются по email без лишних манипуляций с USB-накопителями.

В этой статье разберём уникальную особенность LBP2202N: устройство поддерживает сканирование по сети только через протокол SMB (в отличие от старших моделей с FTPS и Email-), но при этом позволяет гибко настраивать права доступа и пути сохранения. Мы пройдём весь путь: от подключения принтера к роутеру до решения типичных ошибок вроде «Не удалось подключиться к папке» или «Сканер не обнаружен». Особое внимание уделим настройкам безопасности — почему гостевой доступ к SMB может блокироваться в Windows 11 и как это обойти.

Если вы ранее работали с сетевыми сканерами Canon (например, MF269dw или MF4770n), привычные меню здесь отсутствуют. LBP2202N использует упрощённую веб-панель управления, где критические параметры спрятаны в подразделах Network Settings и Scan Settings. Мы покажем, где именно их искать, и предоставим актуальные скриншоты интерфейса (на момент публикации).

1. Подготовка принтера к сетевому сканированию

Прежде чем настраивать сканирование, убедитесь, что Canon LBP2202N корректно подключён к сети. Устройство поддерживает только проводное соединение (Ethernet), поэтому Wi-Fi адаптеры или USB-кабели здесь не помогут. Проверьте следующие моменты:

  • 🔌 Кабель: используйте Cat5e или выше (витую пару). Избегайте удлинителей — они могут вызывать потерю пакетов.
  • 🌐 Роутер: порт принтера должен быть подключён к LAN-порту маршрутизатора, а не к WAN.
  • 💡 Индикаторы: на передней панели LBP2202N должна гореть зелёная лампочка Network (мигает при активности, горит постоянно — соединение установлено).

Если индикатор сети не активен:

  1. Проверьте кабель на физические повреждения.
  2. Перезагрузите роутер и принтер (выключите оба устройства на 30 секунд).
  3. Убедитесь, что на роутере включён протокол DHCP (иначе придётся назначать статический IP вручную).
⚠️ Внимание: Принтер LBP2202N не поддерживает IPv6. Если ваша сеть работает только через IPv6, сканирование по сети будет невозможно. Переключите роутер в режим IPv4 или используйте переходные технологии (например, 6to4).

Чтобы узнать текущий IP-адрес принтера, распечатайте страницу настроек:

  1. Удерживайте кнопку Cancel (❌) на передней панели 5 секунд, пока не замигают все индикаторы.
  2. Отпустите кнопку — принтер распечатает отчёт с сетевыми параметрами.

2. Настройка сетевых параметров через веб-интерфейс

Веб-панель управления Canon LBP2202N позволяет настроить все ключевые параметры сканирования. Для входа:

  1. Откройте браузер и введите IP-адрес принтера (например, http://192.168.1.100).
  2. Введите логин и пароль (по умолчанию: admin/canon или 7654321 — смотрите на распечатанной странице настроек).

Перейдите в раздел Network Settings → TCP/IP Settings. Здесь критически важны два параметра:

  • 📌 IP Address: если используется DHCP, зафиксируйте текущий IP в настройках роутера (привяжите по MAC-адресу).
  • 🔒 Subnet Mask/Gateway: должны совпадать с настройками вашей локальной сети (обычно 255.255.255.0 и 192.168.1.1).

Для стабильной работы сканирования рекомендуем:

Отключить IPv6 в настройках роутера|

Задать статический IP принтеру вне диапазона DHCP (например, 192.168.1.200)|

Установить MTU = 1500 (в разделе Network Settings)|

Отключить энергосбережение на порту роутера (если есть такая опция)-->

После сохранения настроек принтер перезагрузится. Дождитесь, пока индикатор Network не загорится зелёным.

3. Конфигурация протокола SMB для сканирования

Canon LBP2202N поддерживает сканирование только через протокол SMB (Server Message Block). Это означает, что вам нужно:

  1. Создать на ПК или сервере сетевую папку с правами на запись.
  2. Настроить принтер на сохранение сканов в эту папку.

Инструкция для Windows 10/11:

  1. Создайте папку (например, C:\Scans).
  2. Кликните правой кнопкой → Свойства → Доступ → Расшарить.
  3. Выберите пользователя Everyone и дайте права Чтение и запись.
  4. В разделе Безопасность добавьте пользователя Гость (если его нет, включите гостевой доступ в Панель управления → Программы → Включение или отключение компонентов Windows).

Для macOS/Linux используйте Samba:

sudo apt install samba  # Для Debian/Ubuntu

sudo nano /etc/samba/smb.conf

Добавьте в конец файла:

[scans]

path = /home/user/scans


writable = yes


guest ok = yes


create mask = 0777

Перезапустите службу:

sudo systemctl restart smbd
⚠️ Внимание: В Windows 11 по умолчанию отключён протокол SMBv1, который требуется для совместимости с LBP2202N. Включите его через Панель управления → Программы → Включение или отключение компонентов Windows → Поддержка общего доступа к файлам SMB 1.0/CIFS. Альтернатива — обновить прошивку принтера (если доступна версия с поддержкой SMBv2).

В веб-интерфейсе принтера перейдите в Scan Settings → SMB Settings и укажите:

  • 📁 Path: \\IP_компьютера\имя_папки (пример: \\192.168.1.5\Scans).
  • 👤 Username/Password: если папка защищена, укажите данные пользователя с правами записи (для гостевого доступа оставьте пустым).

4. Установка драйверов и ПО для сканирования

Для полноценной работы сетевого сканирования на ПК требуются:

  1. Драйвер принтера: скачайте с официального сайта Canon (выберите модель i-SENSYS LBP2202N → раздел Драйверы).
  2. Утилита Canon MF Scan Utility: нужна для расширенных настроек (цветовые профили, разрешение, формат файлов).

При установке драйвера выберите Сетевой принтер и укажите IP-адрес LBP2202N. В процессе установки может появиться предупреждение о неподписанном драйвере — игнорируйте его (это особенность драйверов Canon для старых моделей).

После установки проверьте доступность сканера:

  1. Откройте Панель управления → Устройства и принтеры.
  2. Найдите Canon LBP2202N → кликните правой кнопкой → Настройки сканирования.
  3. Запустите тестовое сканирование (например, в Paint или MF Scan Utility).

5. Пошаговая инструкция: как отсканировать документ по сети

Когда все настройки завершены, процесс сканирования занимает менее минуты:

  1. Поместите документ в лоток ADF (автоматическая подача) или на стекло сканера. Для ADF максимальная толщина стопки — 50 листов (80 г/м²).
  2. Выберите режим сканирования:
    • 🖼️ Цветной: Color (поддерживает 24-bit, но увеличивает размер файла).
    • ⚪ Чёрно-белый: Black & White (рекомендуется для текстов).
    • 📄 Текст (OCR): только через MF Scan Utility.
  3. Запустите сканирование:
    • С ПК: через MF Scan Utility или контекстное меню принтера.
    • С панели принтера: нажмите и удерживайте Scan 3 секунды (если настроен Quick Scan).

По умолчанию файлы сохраняются в формате PDF (для многостраничных документов) или JPEG (для изображений). Чтобы изменить формат:

  1. Откройте MF Scan Utility.
  2. Перейдите в Preferences → File Format.
  3. Выберите TIFF, PNG или Searchable PDF (с распознаванием текста).
Как отсканировать двусторонний документ?

Для дуплексного сканирования:

1. Поместите документ в ADF лицевой стороной вверх, коротким краем вперёд.

2. В настройках сканера выберите Duplex (в MF Scan Utility это опция 2-Sided Scan).

3. Принтер автоматически перевернёт листы и отсканирует обратную сторону.

⚠️ Не поддерживаются документы с степлером или клеем — они могут застрять в ADF.

6. Типичные ошибки и их устранение

Даже при правильной настройке могут возникать сбои. Вот самые распространённые:

Ошибка Причина Решение
Cannot connect to the folder Неверный путь SMB или права доступа Проверьте имя папки (регистр важен!) и настройки безопасности на ПК
Scanner not found Принтер не в сети или заблокирован фаерволом Пингуйте IP принтера (ping 192.168.1.100), отключите брандмауэр
Invalid username or password Неверные учётные данные SMB Используйте локального пользователя Windows (не Microsoft-account)
Сканер "зависает" на 99% Конфликт с антивирусом (например, Kaspersky) Добавьте исключение для CNMUS16.exe в антивирусе

Если принтер не отвечает на ping:

  1. Проверьте, горит ли индикатор Network.
  2. Подключите принтер напрямую к ПК по Ethernet (минуя роутер).
  3. Сбросьте настройки сети на принтере (зажмите Cancel на 10 секунд).
⚠️ Внимание: После обновления Windows до версии 22H2 многие пользователи сталкиваются с ошибкой 0x0000011b при печати/сканировании. Это связано с новыми требованиями безопасности SMB. Решение: установите на принтер последнюю прошивку (доступна на сайте Canon в разделе Firmware) или откатите Windows до версии 21H2.
💡

90% ошибок сетевого сканирования на LBP2202N связаны с неверными настройками SMB или блокировкой портов антивирусом. Всегда начинайте диагностику с проверки ping и доступа к сетевой папке с другого устройства.

7. Оптимизация качества сканирования

По умолчанию LBP2202N сканирует с разрешением 200 dpi и средним уровнем сжатия. Для улучшения качества:

  • 📏 Разрешение: в MF Scan Utility выберите 300 dpi (для архивных документов) или 600 dpi (для фотографий).
  • 🎨 Цветовой профиль: для текстовых документов используйте Black & White с включённым Text Enhancement.
  • 🗜️ Сжатие: для PDF выберите High Compression (уменьшает размер файла на 40% без потери качества текста).

Для сканирования книг или журналов:

  • Используйте режим Book Scan в MF Scan Utility (автоматически убирает перекос страниц).
  • Отключите Auto Exposure — это предотвратит потерю деталей в тёмных областях.

Совет для многостраничных документов: если скан сохраняется как отдельные файлы, в настройках MF Scan Utility включите опцию Combine into Single File и выберите формат PDF/A для долговременного хранения.

8. Альтернативные способы сканирования

Если сетевое сканирование не удаётся настроить, рассмотрите альтернативы:

  • 🖥️ Локальное подключение: подключите принтер к ПК по USB и используйте MF Scan Utility. Скорость передачи данных выше, но теряется удобство сетевого доступа.
  • ☁️ Облачное сканирование: настройте отправку сканов на email (требуется SMTP-сервер) или в Google Drive через сторонние утилиты вроде Scan to Cloud.
  • 📱 Мобильное сканирование: используйте приложение Canon PRINT Business (доступно для iOS/Android). Поддерживает сканирование по Wi-Fi Direct (если роутер не стабилен).

Для отправки сканов по email:

  1. В веб-интерфейсе принтера перейдите в Scan Settings → Email Settings.
  2. Укажите SMTP-сервер (например, smtp.gmail.com:587), логин/пароль и email получателя.
  3. Включите SSL/TLS (обязательно для Gmail/Yandex).
⚠️ Внимание: При сканировании на email Canon LBP2202N не поддерживает аутентификацию OAuth 2.0. Если ваш почтовый сервер требует её (например, Microsoft 365), используйте "пароли приложений" или настройте локальный SMTP-сервер (например, hMailServer).

FAQ: Частые вопросы по сканированию на Canon LBP2202N

Можно ли сканировать по Wi-Fi?

Нет, Canon LBP2202N поддерживает только проводное подключение (Ethernet). Для беспроводного сканирования потребуется USB-Wi-Fi адаптер с поддержкой RNDIS (но это не гарантирует стабильную работу).

Как сканировать в PDF с поиском по тексту (OCR)?

Установите MF Scan Utility и в настройках сканирования выберите Searchable PDF. Для русского языка дополнительно скачайте языковой пакет OCR с сайта Canon (раздел Software).

Принтер сканирует, но файлы не сохраняются в папку. В чём проблема?

Проверьте:

  1. Права доступа к папке (должны быть Чтение и запись для Everyone).
  2. Наличие свободного места на диске.
  3. Отсутствие блокировки антивирусом (добавьте исключение для папки).

Можно ли сканировать на флешку и одновременно по сети?

Нет, LBP2202N не поддерживает одновременное сканирование в несколько источников. Приоритет отдаётся сетевому сохранению, если оно настроено.

Как сбросить настройки сканера к заводским?

Зажмите кнопку Cancel на 15 секунд, пока все индикаторы не замигают трижды. Альтернативно — в веб-интерфейсе перейдите в Device Settings → Reset All.
